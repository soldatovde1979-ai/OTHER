# Пример-команда

## Задача
Объясни пользователю структуру slash-команды Roo на основе файла, из которого эта команда вызвана.

## Порядок действий
1. Прочитай файл, в котором находится эта команда (или покажи путь к шаблону в `_ROO-AGENTS/commands/`).
2. Перечисли части команды: frontmatter с `description`, заголовок, секции «Задача» и «Порядок действий».
3. Выведи итог в формате: имя команды, где лежит, как вызывается, как добавить свои шаги.

## Ограничения
- Файлы проекта не менять — только ответ.
