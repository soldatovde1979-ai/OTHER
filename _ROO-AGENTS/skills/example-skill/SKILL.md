# Example Skill

## Что делает
Демонстрирует структуру skill: frontmatter с `name` и `description`, далее инструкция для агента.

## Инструкция агенту
1. Прочитай этот файл целиком.
2. Перечисли пользователю, из чего состоит skill (frontmatter, заголовок, секции инструкции).
3. Объясни, куда копировать skill для активации (пути в шапке комментария выше).
4. Файлы проекта не меняй — только ответ.
