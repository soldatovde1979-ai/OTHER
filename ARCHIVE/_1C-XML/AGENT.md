# Движок индекса метаданных 1С — инструкция для ИИ-агента

VERSION = 1.0 · скрипт: `build-index_v1.ps1` · правило поиска: `roo-rule.md`
Среда: Windows, PowerShell 5.1. Все команды — из корня проекта.

## А. Подключить новую конфигурацию
1. Проверить, что выгрузка на месте: в `<Проект>\config\` есть `Configuration.xml` и папки `Catalogs`, `Documents` и т.д. Если выгрузка в другом месте — запомнить путь для `-ConfigPath`.
2. Проверить, что `engine\` лежит в корне проекта (рядом с `config\`). Если нет — скопировать папку `engine\` целиком из исходного проекта.
3. Запустить:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\engine\build-index_v1.ps1
   ```
   Скрипт пересоздаёт только `index\` и файл `.roo\rules\1c-metadata-index.md`. Выгрузку не меняет.
4. Проверить результат (раздел В) и сообщить человеку: дату сборки, число объектов и полей, ошибки.

## Б. Как пользоваться индексом
Правила — в `roo-rule.md` (тот же текст лежит в `.roo\rules\`). Кратко:
- объект ищется в `index\_objects.tsv`;
- поле, тип или «кто ссылается на X» — в `index\_fields.tsv`;
- полная структура объекта — в `index\cards\<Вид>.<Имя>.md`;
- XML из `config\` читать только для того, чего нет в индексе (формы, модули, роли).

## В. Проверка индекса
1. В `index\_build.txt` у каждого вида «N из N». Если меньше — смотреть раздел «Ошибок».
2. Выборочная сверка одного документа (только чтение):
   ```powershell
   (Select-String -Path .\config\Documents\<Имя>.xml -Pattern '<Attribute uuid').Count
   ```
   Число должно совпасть с колонкой «Полей» этого документа в `index\_objects.tsv` (там реквизиты шапки + реквизиты всех ТЧ).
3. Открыть карточку этого документа и сверить 2–3 типа реквизитов с XML.

## Г. Чего не делать
- Не править файлы в `index\` руками — они перезаписываются при каждой сборке.
- Не менять формат индекса без согласования с человеком. Если формат меняется — новая версия скрипта (`build-index_v2.ps1`), и в этом файле, `README.md` и `roo-rule.md` обновить ссылку на версию.
- Не пересохранять `build-index_v1.ps1` без BOM (UTF-8 с BOM обязателен для PowerShell 5.1).
