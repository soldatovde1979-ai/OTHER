# Метаданные и код 1С ERP: работать через MCP code-index, а не через файлы

VERSION = 1.0 · сервер: code-index (bsl-indexer 1.12.0) · репозиторий: `erp`
Установка: setup-code-index_v1.md. Заменяет старое правило 1c-metadata-index.md (индекс tsv).

## Главное
Любой вопрос о структуре или коде конфигурации решай инструментами MCP-сервера `code-index`, в каждом вызове `repo = "erp"`.
Файлы выгрузки (`*.xml`, `*.bsl`) напрямую не читай и не ищи по ним grep-ом: это в разы дороже, и ответ получается неполным.
Точные имена параметров бери из схемы инструмента, не угадывай.

## Какой инструмент для какой задачи
| Задача | Инструмент |
|---|---|
| Реквизиты, типы, ТЧ, измерения и ресурсы регистра, предопределённые | `get_object_structure` |
| Всё об объекте разом: структура, формы, модули, связи | `get_object_profile` |
| Кто ссылается на объект или тип («где используется справочник X») | `get_data_links`, `find_references` |
| Цепочка связей между двумя объектами (для соединений в запросе) | `find_data_path` |
| Движения документа, регистраторы регистра | `get_register_writers` |
| Подписки на события | `get_event_subscriptions` |
| Обработчики формы | `get_form_handlers` |
| Права ролей на объект | `get_role_rights` |
| Найти процедуру по имени, получить её тело | `search_function`, `get_function` |
| Кто вызывает процедуру и кого вызывает она | `get_callers`, `get_callees`, `get_call_tree` |
| Поиск текста в коде | `grep_body`, `grep_code` |
| Прочитать файл или его фрагмент | `read_file` (берёт из индекса, а не с диска) |
| Нестандартная выборка по метаданным | `bsl_sql` (только чтение) |

## Запросы 1С
- Имена таблиц и полей бери только из ответа `get_object_structure`. Если поля нет в ответе, скажи, что его нет. Не придумывай.
- Соединения между объектами проверяй через `get_data_links` или `find_data_path`, а не по смыслу имени.
- Виртуальные таблицы регистров (Остатки, Обороты, СрезПоследних) пиши по стандарту платформы. Измерения и ресурсы для них бери из `get_object_structure`.

## Типовое и доработки
Объекты с префиксами `шх`, `уат`, `т1к`, `eam`, `Itob` — отраслевые доработки, основная зона работы. Объекты без префикса — типовые, менять их можно только по явному запросу человека.
Расшифровки префиксов смотри в `prefix-glossary.md`. Неизвестную аббревиатуру не толкуй: пометь «требует уточнения».

## Если инструмент не отвечает
- `daemon_offline`: индексатор не запущен. Сообщи человеку: «выполни `C:\tools\code-index\bsl-indexer.exe daemon status`». Сам в XML не уходи.
- `unknown_repo`: проверь, что передаёшь `repo = "erp"`.
- Нет 1С-инструментов в списке: сервер подключён без `language = "bsl"` или не переподключён. Сообщи человеку.
- Нужного нет в ответе инструмента: сначала попробуй `get_object_profile`, `grep_code` или `bsl_sql`. Если всё равно нет, скажи прямо, что этого нет в индексе. Файл читай точечно через `read_file` и укажи это в ответе.

## Ответ
- Называй объекты полным именем (`Документ.шхЗаказНаряд`), поля — как в индексе.
- Пиши, откуда взят факт: «по индексу» или «из файла через read_file».
- Если подозреваешь, что индекс устарел (выгрузку обновляли), вызови `get_stats` и сообщи дату или состояние индекса.
