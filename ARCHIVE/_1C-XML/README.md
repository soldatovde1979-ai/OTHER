# Движок индекса метаданных 1С — для человека

VERSION = 1.0 · скрипт: `build-index_v1.ps1`

## Зачем
ИИ-агенту нужно знать реквизиты объектов 1С, чтобы писать запросы. Читать сырой XML выгрузки дорого: в нём на каждый реквизит десятки строк служебных свойств. Скрипт один раз сжимает выгрузку в маленькие текстовые файлы, по которым агент ищет быстро и дёшево.

## Что нужно
- Windows PowerShell 5.1 (есть в Windows по умолчанию). Больше ничего.
- Выгрузка конфигурации из Конфигуратора: `Конфигурация → Выгрузить конфигурацию в файлы...`

## Раскладка проекта
```
<Проект>\
  config\     выгрузка конфигурации (как есть)
  engine\     этот движок — копируется в любой проект целиком
  index\      результат работы скрипта (руками не править)
  .roo\rules\1c-metadata-index.md   правило для Roo (создаёт скрипт)
```

## Запуск — одна команда
Из корня проекта:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\engine\build-index_v1.ps1
```
Если выгрузка лежит не в `config\`: добавить `-ConfigPath "D:\путь\к\выгрузке"`.
Не нужно правило для Roo: добавить `-NoRooRule`.

## Что получится в index\
| Файл | Что внутри |
|---|---|
| `_objects.tsv` | все объекты: вид, имя, синоним, имя таблицы для запроса, число полей, путь к карточке |
| `_fields.tsv` | все поля всех объектов: таблица, поле, тип, синоним, вид поля. Через него же видно «кто ссылается на справочник X» |
| `cards\<Вид>.<Имя>.md` | карточка объекта: стандартные поля, реквизиты с типами, ТЧ, измерения/ресурсы регистров, движения документа, виртуальные таблицы |
| `_build.txt` | когда и из чего собран, сколько обработано, что пропущено, ошибки |

Индексируются объекты с данными (справочники, документы, регистры, перечисления, планы, константы, определяемые типы, общие реквизиты). Формы, модули, роли — нет.

## Когда перезапускать
После каждой новой выгрузки конфигурации. Скрипт пересобирает `index\` целиком — старые данные не смешиваются с новыми.

## Если что-то не так
- **Ошибка про ExecutionPolicy** — запускай именно командой выше (`-ExecutionPolicy Bypass` действует только на этот запуск).
- **Кракозябры вместо русских букв в выводе** — скрипт был пересохранён без BOM. Файл `.ps1` должен быть в «UTF-8 с BOM».
- **«Папка index не пуста и не похожа на индекс»** — в `index\` лежит что-то чужое. Скрипт удаляет только папку, которую сам создавал (где есть `_build.txt`).
- **Ошибки разбора в `_build.txt`** — список файлов. Остальное собрано, код выхода 1.

## Другая конфигурация
Скопировать папку `engine\` в новый проект, положить выгрузку в `config\`, запустить ту же команду. Для ИИ пошагово — `AGENT.md`.
