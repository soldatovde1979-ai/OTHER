# ПРОЕКТИРОЛВАНИЕ СИСТЕМ АВТОМАТИЗАЦИИ И ИИ

## 1. Принципы
* **Детерминированность в недетерминированной среде:** Максимальное ограничение фреймов ответов ИИ с помощью жестких схем и правил.
* **Управление контекстом:** Экономный расход токенов, фильтрация шума и четкая структура передаваемого контекста.
* **Fallback-механизмы:** Обязательное наличие резервного сценария на случай сбоя API или невалидного ответа модели.

## 2. Требования к результату
* Схема взаимодействия (Trigger -> Action -> LLM -> Validation).
* Промпты, конфигурации цепочек или код обработчиков.
