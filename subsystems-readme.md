# Правило документации подсистем

Зафиксировано: 16.09.2026. Область действия — этот репозиторий.

## Определения

- **Подсистема** — каталог, имя которого начинается с `_` (например, `_ROO-AGENTS`, `_VERSION`). Такие каталоги содержат переиспользуемые материалы проекта.
- Каталоги без префикса `_` подсистемами не считаются и этим правилом не покрываются.

## Требования

1. В каждой подсистеме (каталог с префиксом `_`) в её корне обязан лежать `readme.md`.
2. `readme.md` подсистемы отвечает на два вопроса:
   - зачем подсистема нужна (назначение);
   - какие файлы в ней лежат и что каждый из них делает (описание файлов).
3. Если в подсистеме уже есть подробный справочник (например, `reafme.md`), то `readme.md` — тонкий указатель: краткое назначение, карта файлов и ссылка на полный справочник. Дублировать содержимое справочника не требуется.
4. Корневой `README.md` репозитория — общая карта подсистем: перечисляет все подсистемы со ссылками на их `readme.md` и ссылается на этот файл правила.
5. При создании новой подсистемы с префиксом `_` её `readme.md` создаётся вместе с ней, корневой `README.md` дополняется ссылкой на неё.
