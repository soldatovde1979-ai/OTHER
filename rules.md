# Правила проекта

- Windows, терминал среды — cmd.exe: команды через &&, ; только в PowerShell.
- api.anthropic.com с этой машины: прямой TCP 443 таймаутится (WinError 10060) при корректном DNS — блок на уровне соединения (DPI/SNI), обход — прокси/тоннель.
- С текущей сети (svodc01.svo.air.loc, DNS 10.2.190.153) блок по IP-назначению (белый список): открыты только Google-диапазоны и корпоратив; заблокированы Anthropic (все IP, включая переписанный умным DNS 87.228.47.204), Cloudflare, xbox-dns.ru, OpenAI. IPv6 на сети нет. Умный DNS не помогает — блок не DNS-уровня.
- DNS умного DNS 111.88.96.50:53 доступен и отвечает.
- WinINET ProxyServer=10.248.243.1:8080 — мёртвый конфиг от другой сети, не использовать. Без админа обход только через VPN на роутере/другом хосте или внешний прокси с доступного адреса.
- VS Code-расширение называется zoo-code, настройки — zoo-code.* в settings.json.
- Агент — хранитель стандартных подсистем этого пула: следит, чтобы подсистемы не расходились по структуре и правилам, и сообщает о нарушениях.
- Все стандартные подсистемы начинаются со знака `_`: `_<Имя>` (пример — `_VERSION/`). Подсистема без префикса `_` стандартной не считается.
